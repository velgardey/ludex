# Stage A backend runbook

Use Node 26 for the local TypeScript/`node:sqlite` development path. Install with the repository's pnpm version, then run `pnpm --filter @ludex/api dev`. The default API is `http://localhost:4000/api`, bound to loopback. Android emulator uses `http://10.0.2.2:4000/api`; a physical device needs an explicitly chosen LAN host and developer firewall rule. `LUDEX_HOST=0.0.0.0` exposes the development service; do this only in a controlled development network.

The local invite is `LUDEX-LOCAL-BETA`, configurable with `LUDEX_LOCAL_INVITE`. Create actual accounts with a valid email shape and a password of at least 12 characters. This local credential mechanism is development-only. Production refuses `LUDEX_AUTH_MODE=local`. The web settings page must display local mode. Sessions are opaque random 256-bit tokens, stored by hash on the server, expire after seven days and revoke on logout. Native must store tokens in SecureStore. There is no password reset, MFA, mail delivery or refresh token endpoint in the local path.

`LUDEX_DB_PATH` controls the SQLite file; default `.local/ludex.sqlite`. It survives restart. Do not delete it as a troubleshooting shortcut. To reset a disposable test cohort, stop the server and deliberately choose a new database path. Test scripts create and remove their own temporary directories. Copy the database consistently with SQLite's backup mechanism or stop the process before copying the database/WAL files. A restore drill has not been performed.

Use `node scripts/backend-smoke.mts` to exercise real HTTP accounts, publication, restart persistence, export, blocking and deletion. `pnpm --filter @ludex/api test` runs contract/access tests. `pnpm --filter @ludex/api build:functions` emits the Functions artifact in `apps/api/dist`, with the shared sources rewritten to JavaScript. The Azure Functions package `main` points to `dist/apps/api/src/functions/index.js`.

The production wrapper requires Cosmos connection/database/container settings, OIDC issuer/audience/JWKS and explicit CORS origins. It has no local auth fallback. Use protected app settings/Key Vault references for credentials; never commit `local.settings.json`. Invite OIDC subjects through the operator-only `provisionInvitedSubject` service after verifying the tenant/subject identity. No public endpoint accepts roles or subject bindings. Moderator roles require an operator-controlled account change and audit procedure; local moderator email allowlist exists only for local development.

Publication writes are eventual across user and social partitions. Private event/projection/receipt/outbox writes are atomic in one owner partition. Stable event IDs make publication retry harmless. The HTTP local path drains immediately after acceptance; the Functions timer retries every minute. Visibility always rechecks current active event/account and relationship policy before serialization. Deletion atomically disables the account and queues the job before closing the owner write guard. If guard closure or any cleanup batch conflicts, the recoverable job stays queued; the worker closes the guard and retries confirmed cleanup. Local deletion failures retain inaccessible account state; production worker failures must alert an operator before invitation rollout.

API request bodies are capped at 64 KiB; feed pages at 50; local per-process rate limits restrict authentication, writes and reads. These process limits are development controls, not distributed cloud quota guarantees. HTTP allows only explicit origins and returns no-store for all API data. The Functions scaffold also declares CORS; do not use wildcard credential origins.

Before any Azure deployment, prepare the region-specific price quote and `az deployment group what-if` against `infra/main.bicep`. The default eligibility flag creates no resources. Verify Cosmos free-tier availability; the flag must never be changed based on this document alone. Functions uses a candidate on-demand Consumption Y1 plan and Node 22 compiled runtime; regional/runtime support and Flex-vs-Consumption pricing need operator review. No always-ready, Redis, AI Search, APIM, FCM or paid AI has been provisioned.
